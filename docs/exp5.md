## 代码编写要求

### 函数命名规则

- 所有新增的**内核态函数**均以 `k学号_` 作为前缀
  - 例：学号为 `123456` 的同学实现了一个内核态 printf 函数，则函数名应为 `k123456_printf`
- 所有新增的**用户态函数**均以 `u学号_` 作为前缀
  - 例：学号为 `123456` 的同学实现了一个用户态 printf 函数，则函数名应为 `u123456_printf`
- 在本实验手册内提及的新函数均应按照上述要求命名
- 此处所指的函数包括 C 语言函数和汇编代码函数

### 全局变量、结构体命名规则

- 所有新增的**全局变量**和**结构体**的命名也遵循函数命名规则
- 所有在原有数据结构中**新增的字段**，以 `f学号_` 作为前缀；新增结构体中的字段无需遵循此规则
- **局部变量**不用遵循上述规则

### 文件组织规则

- ⚠️ 所有新增的其它结构体（如果需要）、全局变量声明（如果需要）、新的函数声明（如果需要），放到 `include/Lab5.h` 中，该头文件可在 `xinu.h` 中引用
- ⚠️ 所有新增的功能函数，放入 `system` 目录下以 `Lab5_` 为前缀名的源文件中；如果所有函数都在同一个源文件中，则该文件名称可为 `Lab5.c`；也可按照 Xinu 的习惯以函数本身的功能名称参与文件名，如 `Lab5_printf.c`

### 代码修改标记规则

- **单行改动**：应以修改行前一行或当前行尾的注释 `// Lab5 学号` 标记
- **多行修改**：应以首行行前 `/*Lab5 学号: Begin*/` 和末行行后 `/*Lab5 学号: End*/` 标记

### Shell 命令规则

- 在 `shell` 目录下新建一个文件 `xsh_lab5.c`，其中包含一个 shell 命令函数 `xsh_lab5`，参数类型请参考其他 shell 命令
- 在 `shell/shell.c` 的 `cmdtab` 数组中，添加 `{"lab5", FALSE, xsh_lab5}`，注意保证语法正确（后续可在 Xinu 的 `xsh` 中通过 `lab5` 命令来测试所要求题目），并根据后续要求适当修改此处添加的内容

### 2.2 实现用户态 shell 命令 `xsh_lab5`

应完成如下要求：

**a.** `xsh_lab5` 命令运行于**虚拟内存管理模式**下的**用户态**

**b.** `xsh_lab5` 中定义一个局部变量，然后输出该变量的地址，并输出传入 `lab5` 的所有参数（以字符串形式），最后输出学号和姓名（如果中文显示有误，可使用拼音）。如：

```c
// 请自行保证代码正确性
int32 x;
printf("&x=0x%x\n", &x);
for (int i = 0; i < argc; i++) {
    printf("arg-%d: %s\n", i, argv[i]);
}
printf("<学号> <姓名>\n");
// 其他测试代码
```

**c.** 支持虚拟内存管理时，应在 `xsh_lab5` 运行期间，查看内存映射情况，并在 `xsh_lab5` 正常执行结束后，**正确销毁该进程占用的内存空间**，将页目录、页表、栈等空间释放掉，以为其他进程所用

**d.** 「其他测试代码」包括：
- 输出超过文本模式显示器**一行**的字符串（中途不含换行字符 `\n` 和 `\r`，默认一行包含 80 列——如果实现图形模式显示器，可根据实际情况调整）
- 输出多行文本字符串直至**超出一屏**（25 行或自定义的最大显示行数，一屏填满时支持**上滚一行**，如 `printf("abcd\n" * 30)`）
- 输出的字符串包括**数字、字母大小写、各种符号**和**回车/换行/Tab**（`\r`，`\n`，`\t`）等特殊字符

**e.** 在非调试状态下，shell 中执行 `lab5` 命令能够**正常结束**

**f.** 所有输出内容应显示在**显示器界面**（图形界面启动 QEMU 后显示的第一屏，或在原有出现 XSH 界面后按 `Ctrl+Alt+1`）

### 2.3 修改 Shell 进程及 ps 命令

使其满足如下要求：

**a.** Shell 进程运行后所有交互能在**显示器界面**完成（参看 2.2-f），包括 XINU 启动后显示的较大的 XINU 标识（不强制要求以红色显示文字）和 `xsh $` 提示符

**b.** 在命令输入窗口，测试以下按键并记录处理结果（多次截图，并在实验报告中说明各个显示结果对应哪种特殊键操作）：
- 大写锁定键（CapsLock）
- Shift 键
- Ctrl + 字母键（如 `Ctrl+A`）
- Tab 键
- 多种特殊按键之后使用退格键（Backspace、`Ctrl+H`）

**c.** 修改 ps 进程，使其能运行在显示器界面

**d.** 多次执行 `ps` 命令，使得屏幕不足以容纳所有内容，查看最后的效果

**e.** 上步执行结束后，在 shell 的提示符处输入**足够长的内容**（超出一行），查看效果

**f.** 在 shell 的提示符处执行**退格操作**（在没有任何输入之后继续退格），查看效果

**g.** 在**提示符位于屏幕最后一行**时，按下回车键，查看效果

**h.** 在提示符处的**每次按键应及时将字符回显**到屏幕上（即按下 `a`，则屏幕上立刻显示 `a`）

### 2.6 其他说明


> 注意这里数字 `3` 是一个不与其他用户冲突的虚拟屏幕编号，然后在 VNC Viewer 中输入 `IP:3` 的方式连接，IP 为执行上述命令的机器的 IP 地址（如果是本机 WSL，可以使用 `localhost` 或 `127.0.0.1`）⚠️
